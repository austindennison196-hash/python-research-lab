This laboratory separates a proposed interpretation from a formal model and from the evidence obtained by running that model. Start with [the definitions](definitions.md), then read [the transformation rules](transformation_rules.md), [the formal proof](structural_formalism.md), [executed results](results.md), and [the research agenda](research_agenda.md). [Experimental methods](methods.md) describes reproducibility; [development](development.md) explains how to extend the software.

## Claim labels

- **DEFINITION** specifies an object, convention, or rule; it is a choice, not an empirical discovery.
- **THEOREM** is a mathematical statement accompanied by a proof with explicit assumptions.
- **COMPUTATIONAL RESULT** reports the output of a specified finite experiment. It does not prove a claim at every size.
- **CONJECTURE** is a mathematical claim without a proof.
- **HYPOTHESIS** is a proposed explanation requiring investigation and evidence.
- **SPECULATION** is an interpretation without sufficient supporting evidence.

Source code, tests, and notebooks should use these distinctions too. A passing test cannot promote a hypothesis into a theorem, and a diagram cannot establish physical correspondence.
